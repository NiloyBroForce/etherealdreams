💎 Ethereal Art Gallery 

A high-performance, dark-themed digital automotive art gallery. This project showcases custom automotive photography and digital art through a sleek, modern interface built with Next.js 15 and Tailwind CSS v4.

🌟 Features

*   Immersive Dark UI: Built with a custom HSL-based dark theme for a premium feel.
*   Performance First: Leverages Turbopack and Next.js Image optimization for lightning-fast load times.
*   Interactive Socials: Custom-styled social components with branded gradients and hover "glow" effects.
*   Responsive Design: Fully fluid layouts that look great on everything

🛠️ Tech Stack
Framework: [Next.js 15](https://nextjs.org/) (App Router)
Styling: [Tailwind CSS v4](https://tailwindcss.com/)
Icons: [Lucide React](https://lucide.dev/)
Animations: Framer Motion / CSS Transitions
Deployment: Vercel
